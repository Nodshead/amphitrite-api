Amphitrite MetOcean API

High-resolution ocean and atmospheric data along a ship's route or over a defined geographic area. Access forecast, reanalysis, and historical data from a single endpoint.

🌊
Ocean Currents
Satellite-observed surface currents with tidal components. 1/30° (~3.7 km) resolution.
🍃
Wind & Waves
Surface winds, gusts, significant wave height, mean direction and period.
🌡️
SST & Bathymetry
Sea surface temperature from infrared satellites. Fixed ocean depth data.

Authentication

All requests require an API key in the request headers. Keys are provisioned per account and scoped to your access tier (forecast, historical, or both).

# Include in every request
headers = {
    "Content-Type": "application/json",
    "x-api-key": "YOUR_API_KEY_HERE"
}

To request an API key, contact noah@amphitrite.fr.

Route Data

Submit an array of coordinate–timestamp points representing a vessel's route. The API returns MetOcean conditions at each point for the requested variables.

Request

POST /MetOcean
Content-Type: application/json
x-api-key: YOUR_API_KEY

{
  "points": [
    {
      "latitude":  47.2,
      "longitude": -32.0,
      "timestamp": "2025-01-15T12:00:00Z"
    },
    {
      "latitude":  -6.8,
      "longitude":  79.0,
      "timestamp": "2025-01-15T18:00:00Z"
    }
  ],
  "variables":  ["current", "wind", "wave"],
  "task_name":  "voyage-atlantic-jan-2025"
}

Parameters

ParameterTypeRequiredDescription
points array Yes Array of {latitude, longitude, timestamp}. Latitude: −90 to 90. Longitude: −180 to 180. Timestamp: ISO 8601, UTC.
variables array of strings Yes One or more variable names. See Variables table below.
wind_height float No Wind data height above sea surface in metres. Range 10–100. Default: 10.
task_name string No Label for this request — useful for identifying tasks in the task list.
receive_mail boolean No Send an email notification on task start and completion. Default: false.

Python Example

import requests, json

base_url = 'https://api.amphitrite.fr'
headers  = {"Content-Type": "application/json", "x-api-key": "YOUR_API_KEY"}

payload = {
    "points": [
        {"latitude": 47.2,  "longitude": -32.0, "timestamp": "2025-01-15T12:00:00Z"},
        {"latitude": -6.8,  "longitude":  79.0, "timestamp": "2025-01-15T18:00:00Z"},
    ],
    "variables": ["current", "wind", "wave"],
    "task_name": "example-request"
}

response = requests.post(f"{base_url}/MetOcean", headers=headers, json=payload)
if response.status_code == 200:
    print(json.dumps(response.json(), indent=2))

2D Map Data Beta

Request gridded MetOcean data over a geographic bounding box. Returns 2D arrays of values at each grid point — suitable for map visualisations and spatial integration.

This endpoint is in active development. For large bounding boxes, long time ranges, or current data, set "async": true to avoid timeouts.

Request

POST /2DMetOcean
Content-Type: application/json
x-api-key: YOUR_API_KEY

{
  "bounding_boxes": [
    {
      "latitude":  [44, 51],
      "longitude": [-15, -1],
      "timestamp": "2024-05-15T00:00:00Z"
    }
  ],
  "variable":  "wind",
  "async":    false,
  "task_name": "bay-of-biscay-wind"
}

Parameters

ParameterTypeRequiredDescription
bounding_boxes array Yes Single-element array with {latitude: [min, max], longitude: [min, max], timestamp}. Longitude must be in −180/180° convention.
variable string Yes One of: "current", "wind", "wave"
async boolean No Default: false. Set to true for large requests — returns a task ID immediately instead of waiting.
task_name string No Label for this task.
receive_mail boolean No Email notification on completion. Recommended for async requests.
Time range: Pass a two-element array for a range: "timestamp": ["2024-05-15T00:00:00Z", "2024-05-15T06:00:00Z"]. For current data, keep ranges within a single day for best performance.

Response

The conditions object contains 2D arrays where the outer index corresponds to the latitude axis and the inner index to the longitude axis.

{
  "task_id": "uuid-here",
  "status":  "SUCCESS",
  "result": {
    "results": [
      {
        "coordinates": {
          "latitude":  [44.0, 44.25, "...", 51.0],
          "longitude": [-15.0, -14.75, "...", -1.0],
          "timestamp": "2024-05-15T00:00:00Z"
        },
        "conditions": {
          "Winds_10m_Intensity": [[10.1, 10.2, "..."], "..."],
          "Winds_10m_Direction": [[270, 271, "..."],  "..."]
        }
      }
    ]
  }
}

Constraints

  • One bounding box per request
  • Available variables: current, wind, wave only
  • Longitude must be in −180/180° convention (not 0/360°)
  • A single timestamp returns the interpolated value for that exact moment

Visualization

Pass a MetOcean API response directly to /plot_timeseries to receive a ready-made PNG chart. No client-side plotting required.

# 1. Get MetOcean data
metocean_response = requests.post(
    f"{base_url}/MetOcean", headers=headers, json=payload
).json()

# 2. Generate chart
chart = requests.post(
    f"{base_url}/plot_timeseries",
    json=metocean_response,
    headers=headers
)

with open("chart.png", "wb") as f:
    f.write(chart.content)

Async & Task Management

All requests generate a task_id that can be used to check status and retrieve results at any time. For large requests, use the async endpoint to avoid holding an open HTTP connection.

ModeEndpointRecommended for
Synchronous POST /MetOcean Up to ~5,000 points. Results returned directly in the response.
Asynchronous POST /MetOcean/async 100,000+ points. Returns a task_id immediately; poll for results separately.

Polling for Results

import time, requests

base_url = "https://api.amphitrite.fr"
headers  = {"x-api-key": "YOUR_API_KEY"}

# Submit async request
r = requests.post(f"{base_url}/MetOcean/async", headers={**headers, "Content-Type": "application/json"}, json=payload)
task_id = r.json()["task_id"]

# Poll until complete (30s interval for ~5k points; 1800s for ~100k points)
while True:
    status = requests.get(f"{base_url}/task/{task_id}", headers=headers).json()
    if status["status"] in ["SUCCESS", "FAILURE"]:
        break
    time.sleep(30)

Task Status Response

{
  "task_id": "uuid-here",
  "status":  "PENDING",  // "PENDING" | "SUCCESS" | "FAILURE"
  "result":  null,         // populated on SUCCESS
  "error":   null          // populated on FAILURE
}

Task List

Retrieve all tasks to review pending work or recover a task_id after a dropped connection:

# All tasks
requests.get(f"{base_url}/user/tasks",         headers=headers)

# Filtered by status
requests.get(f"{base_url}/user/tasks/PENDING", headers=headers)
requests.get(f"{base_url}/user/tasks/SUCCESS", headers=headers)

Email Notifications

Add "receive_mail": true to your payload to receive:

  • A task start email with task ID, variables requested, and point count
  • A completion email with processing duration summary and full results as a JSON attachment

Notifications go to the email on your account by default. Override with "email": "other@example.com".

Data Specs

The API serves data from three tiers depending on the requested timestamp. All tiers are accessed transparently through the same endpoint — no configuration required.

TierTimeframeUpdated
Standard Historical3+ years agoMonthly
Recent Reanalysis5–90 days agoDaily
Operational ForecastRecent past + 7 days aheadDaily

Ocean Currents

Forecast data is produced by ORCAst, Amphitrite's proprietary deep learning current model trained exclusively on satellite observational data — drifters, altimetry, SST, and chlorophyll measurements. Reanalysis data is produced by the companion model, ORCHIst, which integrates data in both forward and backward temporal directions for higher historical accuracy.

Direction Conventions

Critical for integration: current directions and wind/wave directions use opposite conventions.
FieldConventionExample
Currents_Direction Direction the current is flowing TO 90° = current flowing eastward

Swell_Wave_Mean_Direction
