🎯
Validated current data
Our current forecasts aren't raw model output. Every dataset is reprocessed through our proprietary deep learning pipeline and cross-validated against in-situ oceanographic measurements, ocean buoy networks, and AIS vessel drift data. The result is forecast accuracy that outperforms standard operational products — particularly in coastal and shelf-sea regions where precision matters most.
📡
Highest-resolution currents available
At 2.5–3 km resolution, our current data resolves mesoscale features — eddies, coastal jets, shelf-edge dynamics — that disappear entirely at 10–25 km. This is the resolution range where routing, station-keeping, and subsea planning decisions actually live.
📅
14-day forecast window
Plan further ahead. Our 14-day current forecasts give voyages, installations, and offshore campaigns more lead time than the standard 7-day horizon offered by most operational providers.
🔌
One API, all variables
Currents, winds, waves, SST, and bathymetry in a single request — across forecast, reanalysis, and historical tiers. No separate data feeds, no stitching. The same endpoint handles route-based point queries and 2D gridded requests.

How the current data is different: Most providers serve currents direct from a single numerical model. We blend multi-source satellite observations through a proprietary deep learning architecture, then validate the output against independent in-situ and vessel data before it reaches the API. The validation loop is continuous — accuracy is measured, not assumed.

Authentication

Pass your API key in the request headers on every call. Keys are scoped per account to your access tier (forecast, historical, or both).

headers = {
    "Content-Type": "application/json",
    "x-api-key":      "YOUR_API_KEY_HERE"
}

To request a key: noah@amphitrite.fr

Endpoints

Making a Request

Submit an array of {latitude, longitude, timestamp} points — a route, a set of waypoints, or any collection of locations and times.

POST /MetOcean
x-api-key: YOUR_API_KEY

{
  "points": [
    { "latitude": 47.2,  "longitude": -32.0, "timestamp": "2025-01-15T12:00:00Z" },
    { "latitude": -6.8,  "longitude":  79.0, "timestamp": "2025-01-22T06:00:00Z" }
  ],
  "variables":    ["current", "wind", "wave"],
  "task_name":    "transatlantic-jan-2025"
}

Optional parameters

ParameterTypeDefaultDescription
wind_heightfloat10Wind retrieval height above sea surface in metres. Range: 10–100.
task_namestring—Label this request — makes it identifiable in the task list.
receive_mailbooleanfalseEmail notification on task start and completion (with results attached).

Python example

import requests

response = requests.post(
    "https://api.amphitrite.fr/MetOcean",
    headers={"Content-Type": "application/json", "x-api-key": "YOUR_API_KEY"},
    json={
        "points":    [{"latitude": 47.2, "longitude": -32.0, "timestamp": "2025-01-15T12:00:00Z"}],
        "variables": ["current", "wind", "wave"]
    }
)
print(response.json())

Async & Task Management

All requests generate a task_id. For large requests, use the async endpoint — it returns immediately with a task ID and lets you retrieve results when processing is complete.

ModeEndpointBest for
SynchronousPOST /MetOceanUp to ~5,000 points. Results returned directly in the response.
AsynchronousPOST /MetOcean/async100,000+ points. Returns a task ID immediately; poll GET /task/{id} for results.

Task status response

{
  "task_id": "uuid",
  "status":  "PENDING",   // "PENDING" | "SUCCESS" | "FAILURE"
  "result":  null,          // populated on SUCCESS
  "error":   null           // populated on FAILURE
}

List all tasks for your key at GET /user/tasks. Filter by appending /PENDING or /SUCCESS. Email notifications (with results as a JSON attachment) can be enabled per-request with "receive_mail": true.

2D Map Data Beta

Request gridded data over a geographic bounding box. Returns 2D arrays of values across the grid — suitable for map layers and spatial integration pipelines.

Available variables: current, wind, wave. For large areas or current data over multi-day ranges, use "async": true. 
POST /2DMetOcean
x-api-key: YOUR_API_KEY

{
  "bounding_boxes": [{
    "latitude":  [44, 51],
    "longitude": [-15, -1],
    "timestamp": "2025-01-15T00:00:00Z"
  }],
  "variable": "wind"
}

The response conditions object contains 2D arrays: outer index = latitude, inner index = longitude. Pass a two-element timestamp array for a time range: "timestamp": ["2025-01-15T00:00:00Z", "2025-01-15T06:00:00Z"].

Visualization

Pass any MetOcean API response to POST /plot_timeseries — receive a high-resolution PNG chart with no client-side plotting required. Useful for reports, briefings, and operational dashboards.

chart = requests.post(
    "https://api.amphitrite.fr/plot_timeseries",
    headers=headers, json=metocean_response
)
with open("chart.png", "wb") as f:
    f.write(chart.content)

Output covers all requested variables: current intensity and direction, wave height and period, wind intensity and direction, SST, and bathymetry — each as a labelled panel with min/max/mean indicators.

Direction Conventions

Critical for integration: current directions and wind/wave directions use opposite conventions.
FieldConventionExample
